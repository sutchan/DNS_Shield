# 格式：每行一个域名，# 开头为注释
# 此文件为唯一数据源，通过 index.html 生成其他格式
#
# === 规则说明 ===
# - 空行或 # 开头：注释/无效行
# - 纯域名（如 ad.example.com）：黑名单，阻止解析
# - + 开头（如 +example.com）：白名单，允许解析（覆盖黑名单）
# - ! 开头（如 !example.com）：注释域名，显示在列表中但不断言
# - @ 开头（如 @example.com=0.0.0.0）：自定义 DNS 指向（如 0.0.0.0 或指定 IP）
#
# === 示例 ===
# ad.example.com        # 黑名单：阻止此域名
# +ad.example.com      # 白名单：允许此域名（覆盖黑名单）
# !ad.example.com      # 注释域名：显示用
# @example.com=0.0.0.0 # 自定义 DNS 指向
#
