♿ 无障碍设计

DNS Shield 遵循 WCAG 2.1 AA 级标准，确保色盲、低视力等特殊用户群体也能正常使用应用。 我们通过语义化 HTML、ARIA 属性和适当的颜色对比度来实现这一点。

ARIA 属性

使用 role、aria-label、aria-expanded 等属性增强屏幕阅读器支持。

<button role="tab" aria-selected="true" aria-label="切换到 Hosts 格式">

颜色对比度

所有文本与背景的对比度至少达到 4.5:1，确保可读性。

文本 #1D1D1F / 背景 #FFFFFF → 对比度 21:1 ✓

键盘导航

所有交互元素都可以通过键盘访问，并有清晰的焦点指示。

:focus-visible { outline: 3px solid #007AFF; }

语义化标签

使用正确的 HTML5 语义标签，如 header、nav、main、section、footer 等。

<nav role="navigation" aria-label="主导航">
