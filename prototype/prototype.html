1. 选择域名源 — 点击预设标签快速加载，或在文本框中粘贴你的域名列表

                
2. 生成规则 — 点击「生成规则」按钮解析域名并生成过滤列表

                
3. 选择格式 — Dnsmasq（梅林 / OpenWrt）、Hosts（直接编辑 hosts 文件）、AdGuard（AdGuard Home）

                
4. 导出规则 — 一键复制到剪贴板或下载配置文件

              

            

          


          

            
            

              

                
Dnsmasq — 轻量级 DNS 转发器，适用于梅林、OpenWrt 等路由器固件

                
address=/ad.example.com/0.0.0.0

                
Hosts — 直接修改系统 hosts 文件，支持所有平台

                
0.0.0.0 ad.example.com

                
AdGuard — AdGuard Home / DNS 专用过滤规则格式

                
||ad.example.com^$dnsrewrite=0.0.0.0
