🎨 设计理念

DNS Shield 是一个专业的 DNS 广告过滤规则生成工具，我们追求的是专业、高效、可访问的设计理念。 界面设计强调清晰的信息层次、直观的操作流程和出色的跨设备体验。

核心设计原则

专业感 使用科技蓝紫色调
高效性 清晰的操作流程
可访问 WCAG AA 标准
响应式 完美适配所有设备

核心功能模块

输入域名输入

支持手动输入、URL 加载、文件导入三种方式，提供行号显示和语法高亮

预设规则源

内置 AdGuard、EasyList、NeoHosts、小米广告等多个预设源

输出多格式

支持 Dnsmasq、Hosts、AdGuard、白名单四种输出格式

白名单管理

独立的 whitelist 编辑界面，支持导入/导出和批量操作

i18n多语言

支持 16 种语言，界面实时切换，无需刷新页面

主题切换

支持浅色/深色模式切换，记住用户偏好设置

♿ 无障碍设计

DNS Shield 遵循 WCAG 2.1 AA 级标准，确保色盲、低视力等特殊用户群体也能正常使用应用。 我们通过语义化 HTML、ARIA 属性和适当的颜色对比度来实现这一点。

ARIA 属性

使用 role、aria-label、aria-expanded 等属性增强屏幕阅读器支持。

<button role="tab" aria-selected="true" aria-label="切换到 Hosts 格式">

颜色对比度

所有文字与背景的对比度至少达到 4.5:1（普通文字）或 3:1（大文字）。

主要文字 #1f2937 on #ffffff = 16:1 ✓
次要文字 #6b7280 on #ffffff = 4.5:1 ✓

键盘导航

所有功能都可通过键盘操作，使用 Tab 键导航，Enter 或 Space 键激活。

Tab = 下一个元素 | Shift+Tab = 上一个元素
Enter/Space = 激活按钮 | Esc = 关闭模态框

焦点指示器

使用明显的 :focus-visible 样式，为键盘用户提供清晰的焦点提示。

outline: 2px solid #4f46e5;
outline-offset: 2px;

语义化 HTML

正确使用 header、main、footer、nav 等语义化标签。

<header> = 顶部导航 | <main> = 主要内容
<aside> = 侧边栏 | <footer> = 底部信息

屏幕阅读器支持

图标使用 aria-hidden="true"，配合 aria-label 提供描述。

<i aria-hidden="true">🛡️</i>
<span class="sr-only">DNS Shield 应用</span>

🌙 暗色模式设计

DNS Shield 支持暗色模式，提供更舒适的夜间使用体验。 暗色模式使用较深的背景色，减少眼睛疲劳。

背景色

暗色模式使用 #1f2937 作为主背景色， #374151 作为次级背景色， #111827 用于深层背景（如模态框）。

边框色

强调色

🔄 用户操作流程

DNS Shield 的设计遵循简单直接的工作流程：输入域名 → 解析处理 → 选择格式 → 生成规则 → 下载使用。 每一步都经过优化，确保用户能够快速完成任务。

详细操作步骤

  • 输入域名：在文本框中输入域名，每行一个，支持注释（!开头）和白名单（+开头）
  • URL 加载：输入域名列表的 URL，自动获取并解析内容
  • 预设源：从下拉菜单选择预设源（AdGuard、EasyList 等），自动加载域名列表
  • 解析处理：点击"解析"按钮，自动去重、排序、分类
  • 选择格式：在 Hosts、Dnsmasq、AdGuard、白名单之间切换
  • 配置选项：设置 IP 地址（IPv4/IPv6）、注释等选项
  • 生成下载：点击"生成规则"，然后下载或复制到剪贴板
