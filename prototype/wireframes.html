概述

本文档为 DNS Shield 的组件库规范（Wireframes），与 prototype.html 高保真原型、 shadcn/ 设计系统三位一体。所有组件均基于真实的 src/components/ui/ Radix 封装实现（shadcn/ui 衍生），保证原型与最终代码视觉、交互、API 契约一致。 组件按层级分为：基础组件（Atoms）、复合组件（Composite）、业务组件（Business）。

契约约束：组件文件头注释遵循 // path vX.Y.Z 格式；主要容器须加 kebab-case 语义化 id（如 #app-header、#settings-panel）； 每次改动仅更新被改文件的头注释版本号。

组件使用规则（Rules）

组件落地与组合须遵循的硬性规范，确保跨页面一致性与可维护性。

语义化 id

  • 所有块级容器（div/section/header/main）须加 kebab-case id
  • 与 className 语义一致：#app-header、#input-panel
  • 交互元素尽量带 id，便于 ARIA 关联与测试定位

单一数据源

  • 版本号仅来自 src/config/version.ts 的 APP_VERSION
  • 域名源为 public/domains.txt 单一事实来源
  • 组件状态统一经 AppContext（useT）注入，禁止硬编码文案

变体契约

  • Button 变体：default/secondary/destructive/outline/ghost/link
  • Badge 变体：default/secondary/destructive/outline/success/warning
  • 尺寸仅 sm / default / lg / icon，禁止自定义 px 高度

无障碍（a11y）

  • 表单控件须关联 <Label htmlFor>
  • Switch/Checkbox 用 aria-pressed / role
  • 加载态使用 role="status" aria-live="polite"

动效规范

  • 颜色过渡 .15s cubic-bezier(0.16,1,0.3,1)
  • 按压反馈 active:scale(0.97/0.98)
  • 主题切换整体 background/color .2s 缓动

文件头注释

  • 源码头注释格式 // path vX.Y.Z
  • 每次改动仅更新被改文件的头注释版本
  • 禁止全仓库批量刷写头注释
原型同步：prototype.html（高保真可交互）须与本文档视觉、组件层级、设计令牌保持严格一致； 修改任一处需同步 bump APP_VERSION 并核对 README / package.json 版本三元一致。
