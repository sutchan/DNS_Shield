# DNS Shield — 品牌调色板（Brand Colors）

> 版本：v3.7.42 | 与 `src/app/globals.css` 的 CSS 变量 `--primary` 严格一致

品牌色是 DNS Shield 视觉识别的核心。所有标志、UI 主色、链接、强调元素均取自下方主蓝色阶，禁止随意使用其他蓝色。

## 1. 主色（Primary Blue）

| 名称 | HSL Token | Hex | 用途 |
|------|-----------|-----|------|
| Primary (Light) | `hsl(217 89% 47%)` | `#0D5FE2` | 浅色主题主按钮、链接、标志填充 |
| Primary (Dark) | `hsl(217 85% 55%)` | `#2674F2` | 深色主题主按钮、链接、标志填充 |

```css
:root     { --primary: 217 89% 47%; } /* #0D5FE2 */
.dark     { --primary: 217 85% 55%; } /* #2674F2 */
```

## 2. 蓝色阶（Blue Scale）

用于背景 tint、hover、聚焦环、渐变等派生场景。

| 阶 | Hex | 说明 |
|----|-----|------|
| 50 | `#EAF2FE` | 极浅蓝底（tint / accent 背景） |
| 100 | `#D4E4FD` | 浅蓝底 |
| 200 | `#A9C9FB` | 浅蓝边框 |
| 300 | `#7DAFF9` | hover 浅态 |
| 400 | `#4F8FF6` | hover 态 |
| 500 | `#2A78F4` | 中间调 |
| 600 | `#0D5FE2` | **主蓝（Light）** |
| 700 | `#0A4FC0` | 按下态 / 深蓝文字 |
| 800 | `#2674F2` | **主蓝（Dark）** |
| 900 | `#1E3A8A` | 最深蓝，极少用 |

## 3. 中性色（Neutrals）

| 名称 | Light | Dark | 用途 |
|------|-------|------|------|
| 背景 | `#FAFAFA` | `#111114` | 页面背景 |
| 卡片 | `#FFFFFF` | `#1A1A20` | 卡片 / 浮层 |
| 主文字 | `#1C1D21` | `#F2F2F2` | 标题正文 |
| 次文字 | `#71717A` | `#8C8C95` | 辅助说明 |
| 标志文字 | `#8A94A6` | `#8A94A6` | 标准标志 "DNS Shield" 文字（横版衬线 Georgia） |
| 边框 | `#DEE0E6` | `#33333D` | 分隔线 |

## 4. 语义色（Semantic）

| 语义 | Light | Dark | 用途 |
|------|-------|------|------|
| 成功 | `#16A34A` | `#15803D` | 白名单、通过 |
| 警告 | `#F59E0B` | `#CA8A04` | 提示 |
| 错误 | `#DC2626` | `#991B1B` | 黑名单、危险操作 |

## 5. 使用规则

- 标志填充色强制使用主蓝（Light `#0D5FE2` / Dark `#2674F2`），并配白色防护勾；标志文字使用浅灰 `#8A94A6`（横版衬线 Georgia）。深色背景优先使用反白版 `logo-mono.svg`（白盾蓝勾 + 白字）。
- UI 中主色一律引用 CSS 变量 `--primary`，避免硬编码；需要透明度时用 `hsl(var(--primary) / 0.N)`。
- 旧蓝 `#007AFF`（Apple 系统蓝）已弃用，全面切换为 `#0D5FE2` 体系。
- 单色场景（打印、单色印刷）使用主蓝或纯黑 `#0D1B2E`，禁止灰阶标志。
