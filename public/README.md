# DNS Shield — 品牌资产（Brand Assets）

> 本目录为项目品牌形象的**线上可访问资源**，由构建期 `public/` 直接映射至站点根路径 `/brand/`。
> 应用运行时图标副本位于 `public/` 根目录（见下表），PWA 图标位于 `public/assets/icons/`。

## 目录内容

| 文件 | 说明 | 用途 |
|------|------|------|
| `brand-colors.md` | 品牌调色板规范 | 主色 / 阶 / 中性 / 语义色 |

## 应用级资产（站点根路径）

应用运行时从 `public/` 读取图标：

| 应用路径 | 说明 | 用途 |
|----------|------|------|
| `/brand-banner.svg` | 品牌横幅（蓝渐变 #0D5FE2→#0A1124 背景 + 白色盾牌母版 + "DNS Shield" 白字 + 标语，960×240） | README / 仓库首页 |

## 品牌主色

| 环境 | HSL | Hex |
|------|-----|-----|
| Light | `hsl(217 89% 47%)` | `#0D5FE2` |
| Dark | `hsl(217 85% 55%)` | `#2674F2` |

完整调色板见 `brand-colors.md`。旧蓝 `#007AFF` 已弃用。

## 使用规则

- 优先使用矢量 SVG（任意缩放清晰）；PNG 仅用于需要位图的场景（PWA / 旧客户端）。
- 标准标志配色：蓝色盾牌 `#0D5FE2` + 白色防护勾；标志文字为浅灰 `#8A94A6`（横版衬线 Georgia）。`logo-mono.svg` 仅为深色背景反白变体（白盾蓝勾 + 白字），不得作为浅底主标志。
- 应用内导航栏 Logo 复用 `favicon.svg` 同源的内联盾牌 SVG（`text-primary` 着色），与 `favicon.svg` 逐像素一致。
- SVG 为权威版本，其他尺寸 PNG 由 SVG 导出，避免位图放大失真。
- 禁区：不得拉伸变形、改色（除 mono 反白）、添加阴影/描边、旋转、低透明度弱化至不可辨识。
