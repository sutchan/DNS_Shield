🎨 设计理念

DNS Shield 是一个专业的 DNS 广告过滤规则生成工具，我们追求的是专业、高效、可访问的设计理念。 界面设计强调清晰的信息层次、直观的操作流程和出色的跨设备体验。

核心设计原则

专业感 使用科技蓝紫色调
高效性 清晰的操作流程
可访问 WCAG AA 标准
响应式 完美适配所有设备

📱 响应式布局策略

DNS Shield 采用移动优先的响应式设计，确保在桌面、平板和手机等不同设备上都能提供最佳用户体验。 我们定义了三个主要断点来适应不同的屏幕尺寸。

桌面端 (≥1024px)

≥ 1280px 双栏并排布局，输入输出面板并排显示
1024px - 1279px 自适应单栏布局，保持适当间距

平板端 (768px - 1023px)

768px - 1023px 单栏堆叠布局，面板间距增大，触控友好

移动端 (<768px)

640px - 767px 紧凑布局，统计信息垂直排列
< 640px 最小化布局，按钮全宽，操作最简化

♿ 无障碍设计

DNS Shield 遵循 WCAG 2.1 AA 级标准，确保色盲、低视力等特殊用户群体也能正常使用应用。 我们通过语义化HTML、ARIA属性和适当的颜色对比度来实现这一点。

ARIA 属性

使用 role、aria-label、aria-expanded 等属性增强屏幕阅读器支持。

颜色对比度

所有文字与背景的对比度至少达到 4.5:1（普通文字）或 3:1（大文字），符合 WCAG AA 标准。

键盘导航

所有功能都可通过键盘操作，使用 Tab 键导航，Enter 或 Space 键激活。

焦点指示器

使用明显的 :focus-visible 样式，为键盘用户提供清晰的焦点提示。

语义化HTML

正确使用 <header>、<main>、<footer> 等语义化标签。

屏幕阅读器文本

图标和装饰性元素使用 .sr-only 类隐藏，但保留必要的描述文本。

✨ 交互效果与动画

精心设计的微交互和过渡动画提升用户体验，让界面更加生动和响应迅速。 所有动画都遵循性能优先的原则，避免造成视觉干扰。

📐 设计规格

颜色系统

Primary #4f46e5
Primary Dark #4338ca
Primary Light #6366f1
Success #10b981
Danger #ef4444
Warning #f59e0b
Text Primary #1f2937

字体系统

主要字体：系统字体栈（-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, ...）
代码字体：SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New"

间距系统

使用 4px 基础单位的间距系统：
0.25rem (4px) | 0.5rem (8px) | 0.75rem (12px) | 1rem (16px) | 1.5rem (24px) | 2rem (32px)

圆角系统

0.25rem (4px) - 小圆角（输入框、按钮）
0.5rem (8px) - 中圆角（卡片、面板）
0.75rem (12px) - 大圆角（主要容器、模态框）

阴影系统

阴影小：0 1px 2px rgba(0, 0, 0, 0.05)
阴影中：0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)
阴影大：0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)
